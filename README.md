# JOAT - Jack of All Trades

A pixel-art adventure RPG, played as a home-screen web app.

Play: https://ceurne.github.io/JOAT/

On an iPhone: open the link in Safari, tap Share, then "Add to Home Screen".

This folder is generated by `tools/build_webapp.py` in the game's source project; do not edit it by hand.
The art credits are in the game (Menu > the small "i" button).
